# Rules

What the rule files in `shared/rules/` say today, in plain words. The tables below were generated by reading the JSON files on 2026-11-11 with a small script. They are not written from memory. To refresh them, read the JSON again. Each line gives the code section and the date the value was last checked against the source ("checked on").

**Not legal advice. Not a zoning determination. Parcel lines are not a survey.** Always confirm with the city or township before you design or build.

## How to read this page

- "Confidence" is `verified` (read in the primary text), `secondary` (read in an official guide, or a reading of the text that needs care) or `unverified` (not confirmed).
- "not confirmed" means the file holds no value for this rule. The resolver then takes the value from `default.json`, if it has one, and lists the rule as assumed.
- "none set" means the source sets no limit. For example, Pittsburgh has no share-of-house limit.
- A cell marked "(s)" in a district table is `secondary`.
- For bills, "Effect" says how the value applies: it replaces the town value, or it is a floor ("town may not go under") or a cap ("town may not go over").

### What this means for a backyard home

Read from the rules above and checked with `python -m pipeline.rules resolve` for an RSA-5 detached house (2,000 sq ft lot, 1,400 sq ft house, Council District 2, Ward 30, no alley, with an accessory building):

- A unit inside the house or inside an existing garage is by right, if every test passes.
- A new detached unit, a unit over a garage and an attached addition get "variance". Every residential accessory structure is capped at 130 sq ft and 15 ft (14-604(1)(d)), and the ADU must use an existing building (14-604(11)(c)).
- The size cap is 800 sq ft. The owner must live on site. One ADU per lot.
- A unit inside the house uses the district height (38 ft in RSA-5). A garage unit uses the 15 ft accessory cap.
- The rear setback on an alley (5 ft) and the separation from the house (10 ft) came from `default.json` and are listed as assumed.

### Administrator's Exception

The file sets the base path to by right and a separate path for a new detached unit in a side or rear yard: Administrator's Exception (925.06.G.1(i), G.2 and G.3, as amended by Bill 2025-1545 Section 47, confidence `secondary`). The resolver applies it like this:

| ADU type | Path today |
|---|---|
| Inside the house | by right |
| Attached addition | by right |
| Garage conversion | by right |
| New detached unit | Administrator's Exception |
| Unit over a garage, rear lot line on a way and an accessory building on the lot | by right |
| Unit over a garage, otherwise | Administrator's Exception |

The resolver counts an Administrator's Exception as a legal path (as it does a special exception), so a lot where only a detached unit fits still shows as allowed. The stats file carries a caveat that the detached shares are not by-right shares.

Checked with `python -m pipeline.rules resolve` for an R1D-L detached house (4,000 sq ft lot, 1,400 sq ft house, 28 ft tall): the size cap is 1,000 sq ft, height 30 ft, two ADUs per lot, no owner occupancy, no parking. The rear setback is 5 ft, or 2 ft when the rear lot line is on a way.

Notes from the file:

- Approval path when the lot qualifies: One ADU per lot or parcel, by right, where a residential building is a permitted use.
- Path for a new detached unit in a side or rear yard: Reading: by right per lot, and a town may not require more than 4 ft from side and rear lot lines, so a local exception for side or rear yards would not hold past 4 ft.
- Zoning districts: Every district where a residential building is permitted.
- House types: Any residential building.
- Minimum lot size (sq ft): No lot size test in the bill. By right per lot or parcel.
- ADU forms allowed: Attached, within, or detached on the same lot. Includes units in a detached garage.
- Maximum size (sq ft): Town max may not be under 50% of the house or 850 sq ft, whichever is less, or a whole basement or attic floor.
- Minimum size (sq ft): Town minimum may not be more than 200 sq ft.
- Maximum height of an ADU building (ft): Town limit may not be under 25 ft or the main house height, whichever is less.
- Side setback (ft): No more than 4 ft for a new structure. None for a conversion of an existing structure.
- Rear setback on an alley or way (ft): The rear lot line cap applies on an alley too.
- ADUs per lot: At least one per lot. A town may allow more.
- Town may bar a separate sale: A town may prohibit separate sale or conveyance. It is a town option, not a ban. Separate rental must be allowed.
- Parking spaces required: No additional off-street parking. Lost garage spaces need not be replaced.

How the floors and caps work for one lot: a floor ("town may not go under") raises the town value to the floor when the town value is lower. A cap ("town may not go over") lowers it. The size floor is the lesser of half the house and 850 sq ft, and the height floor is the lesser of 25 ft and the house height, so both need the house size or height. When that fact is missing, the town value stays and a reason says so. Where the town sets no limit at all, a floor or cap does not add one.

Example from the resolver, Philadelphia RSA-5 detached, 1,400 sq ft house, 30 ft tall: every ADU type becomes by right, side and rear setbacks drop to 4 ft, the size floor for this lot is 700 sq ft (so the town's 800 sq ft cap stays), the detached height limit rises to 25 ft and owner occupancy ends.
